\section{Introduction}

Federated learning (FL) enables edge clients to collaboratively train a model without exposing raw data, making it attractive for wireless edge intelligence across mobile devices, vehicles, sensors, and access points. However, wireless FL is inherently constrained by time-varying uplink channels, heterogeneous client resources, and non-independent and identically distributed (non-IID) data. In each communication round, a client can upload only a limited number of bits determined by its instantaneous channel state, power budget, bandwidth allocation, and latency requirement. As foundation models continue to scale, this mismatch between model size and wireless uplink capacity becomes a fundamental bottleneck.

Mixture-of-Experts (MoE) models offer a promising way to scale model capacity through conditional computation. By routing each input to only a small subset of experts, MoE models can maintain large parameter capacity while activating only part of the model per sample. This sparse structure is particularly appealing for federated learning, where different clients may favor different experts according to their local data distributions. Nevertheless, wireless federated MoE learning faces a unique communication-computation mismatch: although each input activates only a few experts, local training over multiple mini-batches may generate updates for many experts, while the client may only be able to upload a small subset of them under its current uplink budget.

Existing communication-efficient FL methods typically follow a post-hoc sparse upload paradigm. The client trains all routed experts locally but transmits only a budget-feasible subset of expert updates afterwards. While this reduces the number of uploaded bits, it does not prevent redundant computation. If an expert is updated locally but eventually not transmitted, its backpropagation, optimizer update, and memory usage do not directly contribute to global aggregation. This inefficiency becomes increasingly severe when the uplink budget is small, the number of experts is large, or local devices are burdened by concurrent application workloads.

To address this challenge, our key insight is that instead of treating the wireless channel as a post-training upload constraint, we inject the channel condition before local backpropagation and use it to shape the local trainable expert subspace. An MoE model already provides informative expert-preference signals before full local training. By running a small number of forward-only probing mini-batches, each client estimates the local utility of every expert using the average router-derived utility over the tokens in each probing mini-batch. Compared with full local training, such probing is inexpensive because it does not require backpropagation through expert blocks or materialization of expert optimizer states. Moreover, since the router typically computes scores for all experts before sparse dispatching, a single probing pass can produce vector-valued feedback over the entire expert pool. This allows the client to compare multiple candidate expert subsets before committing computational resources to local optimization.

We propose a Proactive Channel-Aware Optimization for wireless federated MoE learning, the instantaneous uplink channel determines a client-specific communication budget, which induces a feasible family of uploadable expert subsets. The client then performs lightweight router probing on a few local mini-batches to estimate expert utilities, selects a subset that is both locally useful and communication-feasible, and freezes the remaining experts during formal local training. After training, the client uploads the shared components and the selected expert updates. The server performs expert-wise sparse aggregation over only the clients that upload each corresponding expert. Therefore, the set of trained experts is explicitly aligned with the set of uploaded experts.

\section{Methodology}
As shwon in figure~\ref{Workflow}, we present a channel-aware probe-before-train framework for federated MoE learning. The key idea is to move expert selection before local backpropagation: the wireless channel determines how many expert updates can be uploaded, while lightweight router probing identifies which experts are worth training. Hence, each client trains only the experts that are both useful for its local data and feasible for uplink transmission.

\subsection{System Model}

Federated learning (FL) is a distributed collaborative training paradigm in which multiple clients jointly learn a shared global model without exposing their raw data to the server. Federated learning proceeds iteratively between local training on edge clients and model aggregation on the server. In each communication round, the server first distributes the current global model to the clients participating in training. Then, each client trains its local model using its private local data and uploads the local model parameters or model updates to the server. After receiving updates from multiple clients, the server generates a new global model according to the aggregation strategy and sends it back to the clients for the next round of training. We study an edge FL framework for training a MoE model over edge clients with heterogeneous local data distributions and limited uplink communication resources. Due to the uplink transmission budget $B_i^{(r)}$, client $i$ is allowed to upload only a subset of expert parameters in communication round $r$. Let $\mathcal{E}=\{1,2,\ldots,n_e\}$ denote the set of expert modules, where $n_e$ is the total number of experts. For each client $i$, our objective is to find a feasible set of experts that satisfies the uplink communication budget while maximizing the local expert utilization:
\begin{equation}
\label{optimization objective}
\label{optimization objective}
\begin{aligned}
\mathcal{S}_i^{(r),\star}
=
\arg\max_{\mathcal{S}\subseteq \mathcal{E}}
\quad &
\sum_{j\in \mathcal{S}}\mu_{i,j}^{(r)}
\mathcal{S}_i^{(r),\star}
=
\arg\max_{\mathcal{S}\subseteq \mathcal{E}}
\quad &
\sum_{j\in \mathcal{S}}\mu_{i,j}^{(r)}
\\
\mathrm{s.t.}
\mathrm{s.t.}
\quad
&
\sum_{j\in \mathcal{S}} c_j + c_{\rm sh}
\le B_i^{(r)} ,
\end{aligned}
\end{equation}
where $\mu_{i,j}^{(r)}=\mathbb{E}_{x\sim\mathcal{D}_i}[g_{i,j}^{(r)}(x)]$ denotes the expected utilization of expert $j$ by client $i$, $c_j$ denotes the upload cost of expert $j$, and $c_{\rm sh}$ denotes the upload cost of the shared parameters. By introducing a binary selection variable $z_{i,j}^{(r)}$, Eqn.~\eqref{optimization objective} can be equivalently formulated as a 0-1 knapsack problem:
\begin{equation}
\label{eq:knapsack_general}
\begin{aligned}
\{z_{i,j}^{(r),\star}\}_{j=1}^{n_e}
=
\arg\max_{\{z_{i,j}^{(r)}\}_{j=1}^{n_e}}
\quad &
\sum_{j=1}^{n_e} z_{i,j}^{(r)} \mu_{i,j}^{(r)}
\\
\mathrm{s.t.}
\quad &
\sum_{j=1}^{n_e} z_{i,j}^{(r)} c_j
\le C_i^{(r)},
\\
&
z_{i,j}^{(r)}\in\{0,1\},
\quad j=1,\ldots,n_e ,
\end{aligned}
\end{equation}
where $C_i^{(r)} = B_i^{(r)} - c_{\rm sh}$. The selected expert subset for client $i$ in communication round $r$ is then given by
\begin{equation}
    \mathcal{S}_i^{(r),\star}
    =
    \left\{j\,:\, z_{i,j}^{(r),\star}=1\right\}.
\end{equation}

\subsection{Adaptive Channel-Aware Expert Uploading}
\label{subsec:proactive_channel_aware}
Solving the knapsack problem in Eqn.~\eqref{eq:knapsack_general} requires each client to obtain the expected utilization $\mu_{i,j}^{(r)}$ of every expert at each communication round. Although the exact value of $\mu_{i,j}^{(r)}$ offers a precise characterization of client-specific expert preferences, evaluating it over the entire local dataset incurs significant computational overhead and latency on resource-constrained edge clients, especially when such evaluation is performed repeatedly across rounds. To reduce this overhead, we propose an adaptive channel-aware expert uploading mechanism in \xxx, which incrementally estimates expert utilizations from probe mini-batches and employs a lightweight DP oracle to determine the expert set to upload in the current round.

Specifically, let $Y_{i,j,m}^{(r)}$ denote the observed utilization of expert $j$ at probing step $m$. It is computed as the average normalized gating weight assigned to expert $j$ over the samples in the probing mini-batch:
\begin{equation}
Y_{i,j,m}^{(r)}
=
\frac{1}{|\mathcal{B}_{i,m}^{(r)}|}
\sum_{x\in \mathcal{B}_{i,m}^{(r)}}
g_{i,j}^{(r)}(x),
\end{equation}
where $\mathcal{B}_{i,m}^{(r)} \subseteq \mathcal{D}_i$ denotes the probing mini-batch sampled at probing step $m$. By randomly sampling $\mathcal{B}_{i,m}^{(r)}$ from the local dataset $\mathcal{D}_i$, $Y_{i,j,m}^{(r)}$ provides an unbiased estimate of the expected expert utilization $\mu_{i,j}^{(r)}$. Client $i$ then computes the empirical utilization estimate
\begin{equation}
\widehat{\mu}_{i,j}^{(r)}(m)
=
\frac{1}{m}
\sum_{b=1}^{m} Y_{i,j,b}^{(r)} ,
\end{equation}
and the corresponding confidence interval is given by
\begin{align}
L_{i,j}^{(r)}(m)
&=
\widehat{\mu}_{i,j}^{(r)}(m)
-
\beta_{i,j}^{(r)}(m),
\\
U_{i,j}^{(r)}(m)
&=
\widehat{\mu}_{i,j}^{(r)}(m)
+
\beta_{i,j}^{(r)}(m),
\end{align}
where $\beta_{i,j}^{(r)}(m)$ is the confidence radius. Unlike Hoeffding-type radii~\cite{auer2002finite}, UCB-V-style empirical Bernstein radii~\cite{audibert2009exploration} adapt to the empirical variance of each expert, yielding tighter bounds for low-variance experts while maintaining sufficient exploration for high-variance ones. Accordingly, we use the following empirical-Bernstein confidence radius:
\begin{equation}
\beta_{i,j}^{(r)}(m)
=
\sqrt{
\frac{
2\widehat{\sigma}_{i,j}^{(r)}(m)\log m
}{m}
}
+
\frac{3\log m}{m},
\end{equation}
where $\widehat{\sigma}_{i,j}^{(r)}(m)$ is the empirical variance of 
$\{Y_{i,j,b}^{(r)}\}_{b=1}^{m}$. 

The resulting empirical estimates are then used as surrogate utilities to determine the set of experts uploaded under the current uplink budget. Let $V_{i,m}^{(r)}(j,q)$ denote the maximum empirical utility obtained byselecting a subset from the first $j$ experts under upload budget $q$, where $q=0,1,\ldots,C_i^{(r)}$. The candidate empirical utility associated with including expert $j$ under budget $q$ is defined as
\begin{equation}
\label{eq:dp_take_value_xxx}
T_{i,m}^{(r)}(j,q)
=
V_{i,m}^{(r)}(j-1,q-c_j)
+
\widehat{\mu}_{i,j}^{(r)}(m),
\end{equation}
and the DP recursion is then given by
\begin{equation}
\label{eq:dp_recursion_empirical_xxx}
V_{i,m}^{(r)}(j,q)
=
\begin{cases}
V_{i,m}^{(r)}(j-1,q), & q<c_j,\\
\max\{V_{i,m}^{(r)}(j-1,q),T_{i,m}^{(r)}(j,q)\}, & q\geq c_j ,
\end{cases}
\end{equation}
with initialization $V_{i,m}^{(r)}(0,q)=0$, for $q=0,1,\ldots,C_i^{(r)}$. 

The selected empirical expert subset $\widehat{\mathcal{S}}_{i,m}^{(r)}$ is recovered by traversing the DP table in reverse and inferring the inclusion decisions from the optimal value differences. With the initial state $(j,q)=(n_e,C_i^{(r)})$, expert $j$ is selected if
\begin{equation}
\label{eq:dp_backtracking_condition_xxx}
V_{i,m}^{(r)}(j,q)
\neq
V_{i,m}^{(r)}(j-1,q),
\end{equation}
in which case the remaining budget is updated as
\begin{equation}
\label{eq:dp_backtracking_budget_update_xxx}
q \leftarrow q-c_j .
\end{equation}
Otherwise, expert $j$ is not selected. In either case, the index is decremented as $j \leftarrow j-1$, and the backtracking continues until $j=0$.

After obtaining the current empirical expert subset $\widehat{\mathcal{S}}_{i,m}^{(r)}$, client $i$ evaluates whether this subset is sufficiently reliable under the current confidence intervals. Since the expert uploading problem is a knapsack problem, certifying every selected expert against every unselected expert is overly restrictive and does not directly characterize the stability of the selected subset. Meanwhile, certifying the current solution against all feasible competing subsets would require solving an additional knapsack-type optimization problem at each probing step. Therefore, \xxx further adopts a lightweight local confidence certification criterion based on feasible single-swap alternatives. Let $\mathcal{F}_i^{(r)}$ denote the collection of all feasible expert subsets under the current uplink budget:
\begin{equation}
\label{eq:feasible_subset_family_xxx}
\mathcal{F}_i^{(r)}
=
\left\{
\mathcal{S}\subseteq \mathcal{E}
:
\sum_{j\in\mathcal{S}} c_j
\leq C_i^{(r)}
\right\}.
\end{equation}
For the current empirical solution $\widehat{\mathcal{S}}_{i,m}^{(r)}$, its lower-confidence utility is defined as
\begin{equation}
\label{eq:selected_subset_lcb_xxx}
\mathrm{LCB}_{i,m}^{(r)}
\left(
\widehat{\mathcal{S}}_{i,m}^{(r)}
\right)
=
\sum_{j\in \widehat{\mathcal{S}}_{i,m}^{(r)}}
L_{i,j}^{(r)}(m).
\end{equation}
For any feasible subset $\mathcal{S}\in \mathcal{F}_i^{(r)}$, its upper-confidence utility is defined as
\begin{equation}
\label{eq:competing_subset_ucb_xxx}
\mathrm{UCB}_{i,m}^{(r)}(\mathcal{S})
=
\sum_{j\in \mathcal{S}}
U_{i,j}^{(r)}(m).
\end{equation}
Instead of comparing the current solution with all feasible subsets in $\mathcal{F}_i^{(r)}$, \xxx only considers its feasible single-swap neighborhood. For any selected expert $a\in\widehat{\mathcal{S}}_{i,m}^{(r)}$ and any unselected expert $b\in\mathcal{E}\setminus\widehat{\mathcal{S}}_{i,m}^{(r)}$, define
\begin{equation}
\label{eq:single_swap_subset_xxx}
\mathcal{S}_{a,b}
=
\widehat{\mathcal{S}}_{i,m}^{(r)}
\setminus \{a\}
\cup \{b\}.
\end{equation}
Then, the feasible single-swap neighborhood is
\begin{equation}
\label{eq:single_swap_neighbor_xxx}
\mathcal{N}
\left(
\widehat{\mathcal{S}}_{i,m}^{(r)}
\right)
=
\left\{
\mathcal{S}_{a,b}
:
\mathcal{S}_{a,b}\in\mathcal{F}_i^{(r)}
\right\},
\end{equation}
where $a$ and $b$ range over
$a\in\widehat{\mathcal{S}}_{i,m}^{(r)}$ and
$b\in\mathcal{E}\setminus\widehat{\mathcal{S}}_{i,m}^{(r)}$, respectively.
The probing process terminates if
\begin{equation}
\label{eq:single_swap_stop_xxx}
\mathrm{LCB}_{i,m}^{(r)}
\left(
\widehat{\mathcal{S}}_{i,m}^{(r)}
\right)
>
\max_{\mathcal{S}\in
\mathcal{N}
\left(
\widehat{\mathcal{S}}_{i,m}^{(r)}
\right)}
\mathrm{UCB}_{i,m}^{(r)}(\mathcal{S}),
\end{equation}
or if the maximum probing budget $M_{\max}$ is reached. This condition states that, even under the most pessimistic utility estimate of the selected subset and the most optimistic utility estimate of any feasible single-swap alternative, the current empirical solution remains strictly better. Therefore, the selected expert subset passes a local confidence-based stability test under the current confidence intervals. Compared with exact subset-level certification over $\mathcal{F}_i^{(r)}$, the proposed single-swap stopping rule avoids enumerating all feasible subsets or invoking an additional knapsack DP oracle. Its evaluation only requires checking pairwise replacements between selected and unselected experts, leading to a complexity of $O(|\widehat{\mathcal{S}}_{i,m}^{(r)}|(n_e-|\widehat{\mathcal{S}}_{i,m}^{(r)}|))$ in the worst case. Although this local rule does not certify global optimality over the entire feasible family $\mathcal{F}_i^{(r)}$, it provides an efficient confidence-based stability test and is complemented by the hard probing limit $M_{\max}$.

Finally, suppose the probing process terminates at $m=m_i^{(r)}$. Client
$i$ then outputs the empirical DP solution as its upload expert subset:
\begin{equation}
\label{eq:final_selected_subset_xxx}
\mathcal{S}_i^{(r)}
=
\widehat{\mathcal{S}}_{i,m_i^{(r)}}^{(r)} .
\end{equation}
Only the local updates of experts in $\mathcal{S}_i^{(r)}$ are uploaded to
the edge server, while the remaining expert updates are skipped in the current
round. Therefore, \xxx reduces local utilization-evaluation overhead through
adaptive mini-batch probing and reduces uplink communication overhead through
channel-aware sparse expert uploading. This design is particularly suitable for
wireless edge learning scenarios where clients experience heterogeneous and
time-varying uplink conditions.

\subsection{Expert-Wise Sparse Expert Aggregation}

Since clients may select different expert subsets due to heterogeneous data distributions and time-varying channel budgets, the server performs aggregation in a sparse, expert-wise manner. For expert \(j\), define the set of clients that upload its update in round \(r\) as
\begin{equation}
\label{eq:client_set_expert}
\mathcal{C}_j^{(r)}
=
\left\{
i\in\mathcal{I}^{(r)}:
j\in\widehat{\mathcal{S}}_i^{(r)}
\right\},
\end{equation}
where \(\mathcal{I}^{(r)}\) is the set of clients participating in round \(r\). The server aggregates expert \(j\) only over \(\mathcal{C}_j^{(r)}\), rather than treating missing expert updates as zeros. Specifically, the aggregated expert update is
\begin{equation}
\label{eq:expert_sparse_agg}
\Delta_j^{(r)}
=
\frac{
\sum_{i\in\mathcal{C}_j^{(r)}}
\omega_{i,j}^{(r)}\Delta_{i,j}^{(r)}
}{
\sum_{i\in\mathcal{C}_j^{(r)}}
\omega_{i,j}^{(r)}
},
\qquad
\mathcal{C}_j^{(r)}\ne\varnothing .
\end{equation}
If \(\mathcal{C}_j^{(r)}=\varnothing\), expert \(j\) is kept unchanged in the current round. The aggregation weight \(\omega_{i,j}^{(r)}\) should reflect the effective contribution of client \(i\) to expert \(j\). Instead of using only the total local sample size \(n_i\), we adopt the number of tokens actually routed to and executed by expert \(j\), denoted by \(n_{i,j}^{(r)}\), i.e.,
\begin{equation}
\label{eq:expert_weight}
\omega_{i,j}^{(r)} = n_{i,j}^{(r)} .
\end{equation}
This expert-aware weighting allows each expert to be mainly updated by clients that have sufficient local evidence for that expert, which is consistent with the conditional-computation structure of MoE models under non-IID data.

The global expert parameters are then updated as
\begin{equation}
\label{eq:expert_update}
\boldsymbol{\theta}_{j}^{(r+1)}
=
\boldsymbol{\theta}_{j}^{(r)}
+
\eta_{\rm g}\Delta_j^{(r)},
\end{equation}
where \(\eta_{\rm g}\) is the server-side update step size. For the shared parameters, the server applies standard federated aggregation over all clients that upload the shared update:
\begin{equation}
\label{eq:shared_agg}
\Delta_{\rm sh}^{(r)}
=
\frac{
\sum_{i\in\mathcal{I}^{(r)}}
n_i\Delta_{{\rm sh},i}^{(r)}
}{
\sum_{i\in\mathcal{I}^{(r)}} n_i
},
\end{equation}
followed by
\begin{equation}
\label{eq:shared_update}
\boldsymbol{\theta}_{\rm sh}^{(r+1)}
=
\boldsymbol{\theta}_{\rm sh}^{(r)}
+
\eta_{\rm g}\Delta_{\rm sh}^{(r)} .
\end{equation}
Finally, the updated shared parameters and expert parameters form the new global MoE model, which is broadcast to clients in the next round. In this way, the proposed method closes the loop from wireless-channel-aware budget construction, to confidence-guided local expert identification, to sparse expert-wise server aggregation.
